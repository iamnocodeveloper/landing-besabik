# landing-besabik

Landing de demostración para **Centro Estético Besabik** (Cuenca, Ecuador).

Sitio estático de una sola página (`index.html`, CSS y JS inline), mobile first, con:

- Presentación del centro y servicios con precios de referencia (faciales, corporales, depilación, uñas y cejas)
- Reserva de citas en línea interactiva (elegir servicio, día y hora, con confirmación de ejemplo)
- Bonos y packs de sesiones
- Sección de WhatsApp con atención automática (recordatorios y respuesta 24/7)
- Reseñas (26 reseñas 5.0 en Google) y ubicación
- Botones de contacto que abren WhatsApp (+593 98 428 9097) con mensaje precargado

## Despliegue

Se construye con un `Dockerfile` de dos líneas (`nginx:alpine` + copia de los archivos) y se publica en EasyPanel desde este repositorio.

## Nota

Sitio de referencia hecho por Nocodeveloper. Para la versión final se usan fotos e información reales del negocio.
